# Drone + Metronome

A single-page browser tool for droning notes and keeping time while practicing.

Open `index.html` in a browser — no build step or server required.

## Features

- **Drone notes** — click notes to sustain them, arranged either as a circle of fifths or a piano keyboard layout (toggle between the two).
- **Metronome** — adjustable tempo and subdivision, with selectable time signatures (2/4 through 12/8).
- **Keyboard controls**
  - `↑` / `↓` — master volume up / down
  - `←` / `→` — transpose currently playing notes
  - `+` / `-` — change octave
  - `Escape` — stop all sound
- Responsive layout that fits the whole UI in the viewport across phone, tablet, and desktop sizes.
